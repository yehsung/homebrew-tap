# yehsung/homebrew-tap

Homebrew casks for [IAMCEO](https://github.com/yehsung/IAMCEO) — run your AI coding agents like a company, from one Mac and iPhone app.

```sh
brew install --cask yehsung/tap/iamceo
```

Requires an Apple Silicon Mac on macOS 14 or later. The app is signed with Developer ID and notarized by Apple.

Upgrade with `brew upgrade --cask iamceo`. `brew uninstall --cask iamceo` removes the app and the login service it registered; your data in `~/.iamceo` stays unless you use `--zap`.
